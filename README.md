# Interactive Hotbar
Interactive Hotbar - A 2D interactive hotbar built using Godot & GDScript.

## Features
- 3 items
- 9 hotbar slots by default

## How to Play
Controls:
Left click on hotbar slot then press left click on any of the three images

## Setup & Installation
Prerequisites: Godot version 4.7 or later
Clone the repo: git clone https://github.com
Run the game: press F5 to start
